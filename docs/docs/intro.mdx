# midestic-rn-library

A React Native component library built with **NativeWind (Tailwind CSS)**. It ships buttons, inputs, drawers, modals, pickers and 60+ SVG icons that are all themed through the same `className` API.

## What you get

- **25 components** - `Button`, `Input`, `OTPInput`, `SelectInput`, `Drawer`, `DraggableDrawer`, `Modal`, `Calendar`, ...
- **60+ icons** - every SVG from the design system exported as a component
- **Design tokens** - `primary`, `warning`, `title`, `text`, `background`, ... available as Tailwind utilities
- **TypeScript first** - every component and prop type is exported from the package root
- **Storybook** - an Expo example app with interactive component stories
- **Tree-shakeable source entry** - your app compiles the library source, so NativeWind classes work out of the box

## Quick example

```tsx
import { useState } from "react";
import { Button, Input, ThemedView } from "midestic-rn-library";

export function SignIn() {
  const [email, setEmail] = useState("");

  return (
    <ThemedView safe className="justify-center gap-[16px] px-[24px]">
      <Input label="Email" value={email} onChangeText={setEmail} placeholder="you@example.com" />
      <Button title="Continue" fullWidth size="md" disabled={!email} onPress={() => {}} />
    </ThemedView>
  );
}
```
