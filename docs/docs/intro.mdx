# midestic-rn-library

A personal React Native component library built with **NativeWind (Tailwind CSS)**. Add only the components you choose; this library complements React Native's built-in components, it is not a replacement for them.

## What you get

- **25 components** - `Button`, `Input`, `OTPInput`, `SelectInput`, `Drawer`, `DraggableDrawer`, `Modal`, `Calendar`, ...
- **60+ icons** - every SVG from the design system exported as a component
- **Design tokens** - `primary`, `warning`, `title`, `text`, `background`, ... available as Tailwind utilities
- **TypeScript first** - copied components keep their TypeScript prop definitions
- **Storybook** - an Expo example app with interactive component stories
- **Copy only what you need** - the CLI adds selected components and their helper files as editable source in your app

## Quick example

```tsx
import { Button } from "./src/components/ui/button";

export function Welcome() {
  return <Button title="Get started" onPress={() => {}} />;
}
```
